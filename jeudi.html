Saisonnalité : 38 % CA en été (randonnée), 28 % en hiver (ski). Marché outdoor France : +12 % en 2023, e-commerce outdoor = 31 % des achats.

Contexte du lancement e-shop
Budget alloué : 40 000 €. Aucune compétence technique en interne. Solution déployée : WordPress + WooCommerce (thème générique). Catalogue partiellement importé : 480 références sur 1 200. Contrainte principale : intégration ERP Sage pour la synchronisation des stocks et commandes.
Analytics 6 mois post-lancement (Google Analytics)
  • Trafic : 4 200 sessions/mois · 68 % mobile · CVR mobile 0,4 % / desktop 1,9 %
  • Sources : direct 45 % · organique 28 % · social 14 % · payant 8 % (Google Shopping, 300 €/mois) · referral 5 %

  • CA digital : 2 805 €/mois (objectif initial : 15 000 €/mois)
  • Taux de retour produits : 18 % (élevé pour le secteur)
Problèmes techniques identifiés
  • Temps de chargement mobile : 8,2 s (Core Web Vitals rouge · benchmark : <2,5 s)
  • Aucun système de filtrage/recherche produits · 0 avis clients sur les fiches
  • Photos non optimisées : format JPEG, 3-8 Mo par image
  • Pas de paiement fractionné (3-4× attendu sur l'outdoor premium)
  • Catalogue partiellement importé : seulement 480 références sur 1 200
Objectifs année 2
  • CA digital : 15 000 €/mois (×5,3 vs actuel) · Taux de conversion : 2,5 %
  • Trafic : 20 000 sessions/mois · Taux de rebond : <45 %
  • Part digital dans CA total : 10 %
Mission examen : Auditez les performances digitales de NatureSport, identifiez les 5 chantiers prioritaires et recommandez une solution CMS (justification technique + coût + intégration ERP Sage). Proposez un plan d'actions pour atteindre 15 000 € de CA digital mensuel à 12 mois.

Q2
Critères influençant le taux de conversion e-commerce
👆 Cliquer pour voir la réponse
Facteurs de conversion
  • UX & Navigation : architecture claire, filtres efficaces
  • Vitesse : chaque seconde supplémentaire → -7% de conversion
  • Fiches produit : photos HD, descriptions, avis, vidéos
  • Réassurance : CGV, politique retour, labels, paiement sécurisé
  • Tunnel simplifié : max 3-4 étapes, guest checkout
  • Multi-paiement : CB, PayPal, virement, 3x
  • Mobile-first : >60% du trafic e-commerce
Q3
Pourquoi l'optimisation mobile est-elle essentielle ?
👆 Cliquer pour voir la réponse
Mobile-First
  • >60% du trafic e-commerce FR vient des smartphones
  • Google Mobile-First Indexing : version mobile indexée en priorité
  • Site non optimisé → pénalise le SEO
  • Core Web Vitals mesurent l'expérience mobile
  • Conversion mobile 2-3x inférieure si expérience mauvaise
Bonnes pratiques : boutons ≥44px, Apple Pay/Google Pay, formulaires simplifiés
Q4
Éléments renforçant la confiance des internautes
👆 Cliquer pour voir la réponse
Éléments de réassurance
  • Avis clients vérifiés (Trustpilot, Google Reviews)
  • Labels : Trusted Shops, FEVAD, ecommerce europe
  • HTTPS + logo CB/PayPal + 3D Secure
  • CGV, mentions légales, politique retour, SIRET visibles
  • Contact accessible : tel, email, chat live
  • Garanties claires : délai livraison, retour 30 jours
  • Preuve sociale : nb clients, note moyenne
Q5
Comment optimiser le tunnel de conversion ?
👆 Cliquer pour voir la réponse
Optimisation tunnel
Étapes : Fiche produit → Panier → Identification → Livraison → Paiement → Confirmation

  • Max 3-4 étapes
  • Guest checkout disponible
  • Frais de livraison affichés dès la fiche produit
  • Sauvegarde automatique du panier
  • Indicateur de progression visible
  • Pas de menu de navigation dans le checkout
  • Récapitulatif commande visible à droite
Cas pratique : NatureSport (lancement e-shop)
→ Fonctionnalités prioritaires (Must Have / Should Have)▼

Must Have :

  • Catalogue avec filtres (catégorie, taille, prix, marque)
  • Moteur de recherche interne performant
  • Fiche produit complète (photos, vidéo, avis, tableau des tailles)
  • Panier et tunnel d'achat simplifié
  • Multi-paiement (CB, PayPal, virement)
  • Gestion stocks synchronisée avec ERP Sage
  • Click & Collect (retrait en magasin)
  • Espace compte client (historique, retours, favoris)

Should Have :

  • Programme de fidélité
  • Recommandations produits (cross-sell, up-sell)
  • Avis clients vérifiés · Blog/conseils outdoor
→ Risques à anticiper au lancement▼
  • Risque SEO : perte de positionnement → plan de redirections 301, suivi Search Console
  • Risque synchronisation ERP : désynchronisation stocks → tests d'intégration approfondis
  • Risque performance : chargement lent avec 1200 refs + images HD → CDN, compression, cache
  • Risque sécurité : fraude paiement, RGPD → SSL, 3D Secure, politique cookies
  • Risque adoption interne : équipe non technique → formation et documentation
  • Risque budget : fonctionnalités personnalisées → MVP puis évolutions

Web Analytics & Mesure de la Performance

Prof. Prieto José-Tomas

Questions de connaissances
Q1
Pourquoi mettre en place un plan de marquage ?
👆 Cliquer pour voir la réponse
Plan de marquage
Document recensant tous les événements et interactions à tracker sur le site.

Pourquoi c'est indispensable :
  • Garantit la cohérence et la fiabilité des données
  • Évite les oublis de tracking (events, conversions)
  • Facilite la communication marketing ↔ développeurs
  • Mesure précise du ROI de chaque action
  • Base de travail pour les dashboards
Q2
Différence entre métrique et dimension
👆 Cliquer pour voir la réponse
Métrique vs Dimension
Dimension (Quoi/Qui) : attribut qualitatif pour segmenter.
Ex : canal d'acquisition, pays, appareil, page visitée

Métrique (Combien) : valeur numérique quantifiant une performance.
Ex : sessions, taux de conversion, revenus, durée de session

Exemple combiné : Taux de conversion (métrique) par canal (dimension) sur mobile (dimension)
Q3
Définissez les métriques clés e-commerce
👆 Cliquer pour voir la réponse
Métriques clés
Taux de rebond : % de sessions quittant le site après 1 seule page sans interaction. >70% = signal négatif (mauvaise acquisition ou expérience). En GA4 : indicateur "taux d'engagement" (inverse)

Taux de conversion : Conversions / Sessions × 100. Benchmark e-commerce FR : 1,5 à 3%

Panier moyen : CA total / Nombre de commandes. Leviers : upsell, cross-sell, seuil de livraison gratuite

CAC (Coût d'Acquisition Client) : Total dépenses marketing / Nb nouveaux clients acquis. Doit être < CLV. Ratio CLV/CAC idéal ≥ 3

Q5
Méthodologie pour diagnostiquer une baisse du CA digital
👆 Cliquer pour voir la réponse
Diagnostic en 5 étapes
  • 1. Isoler : baisse du trafic ou de la conversion ?
  • 2. Analyser par canal : quel canal a baissé ?
  • 3. Analyser par segment : mobile/desktop, nouveaux/connus ?
  • 4. Analyser le funnel : à quelle étape les abandons ?
  • 5. Croiser avec événements externes : update Google, coupure campagne ?
Outils : GA4 · Search Console · Rapport d'exploration GA4 · Alertes auto
Cas pratique : NatureSport (diagnostic performance)
→ Comment diagnostiquer la situation ?▼
  • 72% de rebond → problème d'acquisition (mauvais ciblage) ou d'expérience landing page
  • 0,8% de conversion vs 2,5% secteur → friction importante dans le parcours d'achat
  • Panier moyen 85€ dans la norme outdoor → pas le problème prioritaire
Questions à investiguer : D'où vient le trafic ? Depuis quel device ? À quelle étape du funnel les utilisateurs abandonnent-ils ? Quelles pages ont le taux de rebond le plus élevé ?
→ Actions recommandées▼
  • Optimisation UX mobile : refonte responsive du tunnel, taille des boutons, simplification checkout
  • Améliorer les fiches produit : photos HD, avis, tableau des tailles, vidéos
  • Retravailler campagnes SEA : mots-clés trop génériques → cibler l'intention transactionnelle
  • Éléments de réassurance : label Trusted Shops, politique retour en header, chat live
  • Optimiser la vitesse : compression images, CDN, lazy loading
  • Récupération panier abandonné : email auto H+1 et H+24 avec code promo

Prof. Orlowski Alexandre

Questions de connaissances
Q1
Avantages et limites d'un CMS e-commerce
👆 Cliquer pour voir la réponse
CMS : Pour / Contre
Avantages :
  • Déploiement rapide sans dev from scratch
  • Écosystème plugins/extensions étendu
  • Mises à jour sécurité gérées (SaaS)
  • Interface accessible aux non-techniques
Limites :
  • Personnalisation limitée
  • Dépendance éditeur (surtout SaaS)
  • Coûts abonnement cumulés
  • Évolutivité contrainte pour grands sites
Q2
Comparatif des solutions e-commerce (Shopify, Woo, PrestaShop, Magento)
👆 Cliquer pour voir la réponse
Comparatif CMS
Shopify : SaaS hébergé · Très facile, pas de dev requis · 29-299€/mois + commissions · Petit à moyen catalogue · Idéal : TPE/PME, lancement rapide

WooCommerce : Open Source (plugin WordPress) · Facilité modérée · Faible coût (hébergement + plugins) · Idéal : blog + boutique, petits catalogues

PrestaShop : Open Source · Compétences PHP requises · Faible coût (hébergement + modules) · Idéal : PME françaises, catalogues moyens à grands

Magento (Adobe Commerce) : Open Source / Cloud · Dev expert requis · Coût élevé (projet sur mesure) · Idéal : grands comptes, très gros catalogues
Q3
Critères de choix d'une solution e-commerce
👆 Cliquer pour voir la réponse
Critères de choix
  • Budget total (implémentation + abonnement + plugins + maintenance)
  • Taille du catalogue (références, variantes, langues)
  • Compétences internes (équipe technique ?)
  • Évolutivité sur 5 ans
  • Intégrations nécessaires (ERP, CRM, paiement)
  • Besoins de personnalisation
  • Sécurité et conformité (RGPD, PCI-DSS)
  • Support et communauté
Q4
Importance de l'intégration CRM et ERP
👆 Cliquer pour voir la réponse
Intégrations ERP / CRM
Intégration ERP :
  • Synchronisation auto des stocks (évite surventes)
  • Commandes traitées de façon unifiée
  • Prix et promotions en temps réel
Intégration CRM :
  • Historique d'achat centralisé
  • Segmentation automatique pour les campagnes
  • Scoring et détection du churn
Sans intégration : risque d'erreurs, stocks désynchronisés, vision éclatée
Q5
Coût Total de Possession (TCO) d'une plateforme e-commerce
👆 Cliquer pour voir la réponse
TCO : Formule
TCO = Coûts initiaux + Coûts récurrents + Coûts cachés

Initiaux : licence/intégration, développement, design, imports de données

Récurrents : abonnement SaaS, modules, maintenance, formation

Cachés : commissions Shopify (0,5-2%), frais transaction paiement, coût migration future

Cas pratique : NatureSport (recommandation de solution)
→ Recommandation (Budget 40 000€, ERP Sage, 1 200 réf.)▼

Recommandation : PrestaShop ou Shopify selon la priorité.

  • PrestaShop → priorité autonomie et budget maîtrisé : open source, forte communauté française, bons modules ERP Sage
  • Shopify → priorité rapidité de lancement : déploiement rapide, bonne expérience mobile native. Attention aux coûts récurrents

Dans les deux cas : prévoir l'intégration Sage dès la phase de conception.

→ Plan de migration recommandé (5 phases)▼
  • Phase 1 · Préparation (4 sem) : export des données, cahier des charges, choix solution, sélection prestataire
  • Phase 2 · Développement (8 sem) : paramétrage, personnalisation, intégration ERP, import catalogue
  • Phase 3 · Tests (2 sem) : recette fonctionnelle, tests performance, mobile, paiement
  • Phase 4 · Migration (1 week-end) : bascule DNS, redirections 301, vérification données importées
  • Phase 5 · Post-lancement (4 sem) : monitoring intensif, correction anomalies, formation équipe, premiers KPI
Risque principal : Perte SEO → plan de redirections 301 exhaustif + suivi Search Console avant/après migration

Synthèse Transversale : Méthode Examen

Structure de réponse recommandée pour les études de cas

🎯 Ce cadre mobilise les 3 matières du Bloc 5 + les blocs précédents. Apprenez cette structure par cœur !
Structure de réponse en 5 parties

1. Diagnostic SWOT

  • Forces (Strengths) : ce qui fonctionne déjà
  • Faiblesses (Weaknesses) : problèmes internes identifiés
  • Opportunités (Opportunities) : potentiel de croissance externe
  • Menaces (Threats) : risques concurrentiels ou marché

2. Plan d'action priorisé

  • Quick wins (0-3 mois) : actions immédiates à fort impact
  • Moyen terme (3-6 mois) : optimisations structurelles
  • Long terme (6-12 mois) : développements stratégiques

3. KPI stratégiques

  • 1 KPI par levier activé
  • Objectif chiffré et délai précis pour chaque KPI
  • Sourced sur des benchmarks sectoriels

4. Dashboard de pilotage

  • Acquisition : sessions, CAC par canal, impressions
  • Conversion : taux de conversion, CA, funnel commande
  • Fidélisation : réachat, CLV, emailing, NPS
  • Notoriété : reach, engagement, share of voice

5. Facteurs Clés de Succès

  • Cohérence des leviers activés
  • Approche data-driven (décisions basées sur les données)
  • UX au cœur de la stratégie
  • Contenu de qualité aligné sur l'intention utilisateur
  • Mesure continue et itérations rapides
Formules à retenir pour l'examen
Taux de conversion : Conversions / Sessions × 100
CAC : Dépenses marketing / Nb nouveaux clients
CLV : Panier moyen × Fréquence d'achat × Durée de vie client
ROI : (Revenus générés - Coût) / Coût × 100
ROAS : Revenus générés / Budget publicitaire dépensé (objectif > 4)
Ad Rank Google : Enchère × Quality Score × Contexte
Taux d'engagement : (Interactions / Reach) × 100. Benchmark Instagram : bon >3%, excellent >6%
Ratio CLV/CAC idéal : ≥ 3 (si <3 = modèle non rentable)
